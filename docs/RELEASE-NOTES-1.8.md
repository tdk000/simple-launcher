# Release 1.8 — attach these files

Upload to the GitHub release page together with the notes below:

- `SimpleLauncher-legacy.apk`   — Android 5.0–7.x (target 23)
- `SimpleLauncher-android17.apk` — Android 8+ (target 37)

## Notes (copy-paste for the release body)

Search that searches your phone, an alphabet bar for two alphabets, and a
civilised way out.

- Type in the search field: the grid filters live over installed apps
  (label or package, any language). Keyboard search key: top local hit,
  or web search when the phone has no match.
- Index bar on the right: #, A–Z, А–Я. Tap or drag to jump.
- Long-press the clock → *Switch default launcher…* to leave.
- Everything else from 1.7: work profiles, six sorts, two flavors.

Signing key unchanged since 1.0 — installs as an update over 1.x.
